# Professionalism & Ethics (The Clean Coder)

Software engineering is a craft that requires discipline, ethics, and a commitment to quality.

## 👮 The Boy Scout Rule
*Always leave the code better than you found it.*
- If you touch a file to fix a bug, fix a bad variable name or a messy function while you're there.

## 💬 The Power of "No" and "Yes"
- **Professionalism is saying No**: If a deadline is impossible without compromising quality, say NO. Offer alternatives. Don't "try" or "hope."
- **Meaning what you say**: If you say YES, it must be a commitment based on real data and certainty.

## 🧪 Tests as a Professional Requirement
- Writing tests is not "optional" or "extra." It is a fundamental part of the job. 
- Code without tests is **Legacy Code** by definition.
- Aim for the **F.I.R.S.T.** principle: Fast, Independent, Repeatable, Self-Validating, Timely.

## 📉 Sustainable Pace
- Overtime is a sign of failure. It reduces quality and creates more bugs.
- Maintain a pace you can sustain indefinitely without burnout.
