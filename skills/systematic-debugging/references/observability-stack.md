# Observability Stack & Tools

Modern debugging relies on data, not just code. Use these tools to gather evidence.

## 📊 Metrics & APM
- **Prometheus / Grafana**: Real-time metrics and dashboarding.
- **DataDog / New Relic**: Full-stack application performance monitoring.

## 🪵 Log Aggregation
- **ELK Stack (Elasticsearch, Logstash, Kibana)**: Deep log analysis.
- **Grafana Loki**: High-efficiency, labels-based logging.

## 🕵️ Distributed Tracing (OpenTelemetry)
- **Jaeger / Zipkin**: Visualize request paths across microservices.
- **HoneyComb**: High-cardinality analysis to find "needles in haystacks."

## 🚨 Error Tracking
- **Sentry / Bugsnag**: Catch unhandled exceptions and link them to specific commits/users.

## 🧪 Interactive & Time-Travel
- **VS Code Debugger**: Step-through local code.
- **rr (Record & Replay)**: Record a failure and replay it as many times as needed for C/C++ or low-level systems.
- **Redux DevTools**: Inspect state transitions in frontend apps.
