# Frontend & Product Design (Tier 2)

Create "Apple-level" product experiences focusing on radical simplicity, cognitive ease, and visual excellence. Prioritize accessibility, consistency, and delight.

## 🔄 Operating Pipeline

### Step 1 — UX Mapping
- Map the entry point, actions, feedback, and outcome of the flow.
- Ensure every action has an immediate visual response.

### Step 2 — Visual Language & Tokens
- Define the semantic color palette, typography scale, and spacing grid.
- Use **Design Tokens** to ensure consistency across platforms.

### Step 3 — Component Construction
- Build atoms (buttons, inputs) before organisms (modals, headers).
- Enforce accessibility (WCAG AA) at the atomic level.

### Step 4 — UI Critique & Polish
- Perform a structured critique focusing on hierarchy and performance (perceived).
- Add "surprising delight" (micro-animations, smooth transitions).

---

## 🎨 Design Pillars
1. **Radical Simplicity**: Remove everything that isn't essential.
2. **Cognitive Ease**: The user should never have to think about how to use the UI.
3. **Accessibility First**: Accessibility is a core requirement, not an add-on.
4. **Systemic Coherence**: Every element must feel like part of a unified whole.
