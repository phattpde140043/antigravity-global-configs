# BFRI Model: Pre-Implementation Assessment

Use the BFRI model to evaluate any non-trivial feature or change before starting the PLAN phase.

## 🧱 B: Benefit (Giá trị)
- What business value does this change provide?
- Who is the primary stakeholder?
- How does it align with project goals?

## 🛡️ F: Feasibility (Tính khả thi)
- Do we have the technical capability to implement this?
- Are there any blocking dependencies?
- Is the estimated effort realistic?

## 📈 R: Risk (Rủi ro)
- What could go wrong?
- What is the impact on existing systems?
- Are there security or performance concerns?

## 🏗️ I: Impact (Ảnh hưởng)
- Which components/services will be touched?
- Does this require infrastructure changes?
- Is there a need for data migration?
