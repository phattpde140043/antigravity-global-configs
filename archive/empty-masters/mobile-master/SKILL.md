# Mobile Development Master

Expertise in building high-performance, beautiful mobile applications.

## 🚀 Flutter Excellence
- **State Management**: Expert use of Riverpod, Bloc, or Provider.
- **Performance**: Optimize widget build cycles, use `const` constructors, and minimize off-screen rendering.
- **Native Integration**: Use MethodChannels for platform-specific capabilities (iOS/Android).
- **Responsive UI**: Handle different screen sizes, orientations, and safe areas.

## 🏗️ Mobile Architecture
- **Layered Design**: Separation of UI, Business Logic, and Data.
- **Offline-First**: Implement local caching (Hive, SQLite) and synchronization strategies.
- **Dependency Injection**: Use `get_it` or `riverpod` for clean service management.

## 🛡️ Best Practices
- **Asset Optimization**: Use appropriate image resolutions and vector graphics (SVG).
- **Animation**: Use implicit and explicit animations for a premium feel without dropping frames.
- **Security**: Secure storage for tokens and biometric authentication integration.

## 📋 Verification Checklist
- [ ] Is the state management strategy consistent and scalable?
- [ ] Are widgets optimized to prevent unnecessary rebuilds?
- [ ] Does the UI handle safe areas and different aspect ratios?
- [ ] Is data cached locally for offline support?
- [ ] Are platform-specific design guidelines (Material/Cupertino) respected?
