# Documentation Standards

## 📜 Architecture Decision Records (ADR)
Every significant architecture decision must be documented as an ADR.
- **Title**: Descriptive name of the decision.
- **Context**: Why was this decision made? What were the alternatives?
- **Decision**: What did we choose?
- **Status**: Proposed, Accepted, Superceded.
- **Consequences**: What are the trade-offs?

## 🗺️ C4 Diagrams
Use the C4 model for visual documentation (Refer to `c4-model.md`).

## 📚 README.md
Every repository and major module must have a clear README:
- **Project Name & Description**.
- **Prerequisites & Setup**.
- **How to Run & Test**.
- **Architecture Overview**.
- **API Endpoints (if applicable)**.
